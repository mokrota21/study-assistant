---
description: Pull an excluded-but-adjacent concept into scope
argument-hint: <concept> [subject]
---

Expand scope into: **$ARGUMENTS**

This is the *only* way scope grows. Never widen it because a topic came up naturally.

1. Confirm the concept is currently in the excluded-but-adjacent list in `plan.md`. If it is
   not there at all, say so and treat it as a new proposal.
2. Research it incrementally — what it needs as prerequisites, what it unlocks, how much
   material. Save anything collected into `materials/`.
3. Update `plan.md`: move it into the concept table with its prerequisite edges, remove it
   from the excluded list, and add any *new* adjacent concepts it exposes to that list.
4. `register_concepts` and `seed_cards`.
5. Re-run `propose_schedule` if the horizon no longer fits.
6. **Tell the user what it costs** — how many extra blocks, how much longer to the колоквиум.

In scoped mode, note explicitly that this takes the subject beyond the book's contract, and
record it in `plan.md` under the contract section.
